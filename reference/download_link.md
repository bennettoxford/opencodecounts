# Download link with an info tooltip

A small text link with a download icon, styled like the switch labels.

## Usage

``` r
download_link(id, text)
```

## Arguments

- id:

  Output id of the matching
  [`shiny::downloadHandler()`](https://rdrr.io/pkg/shiny/man/downloadHandler.html).

- text:

  Character, the tooltip body that explains the download.
