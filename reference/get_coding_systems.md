# Helper function to get the coding system of codelist versions from OpenCodelists

Helper function to get the coding system of codelist versions from
OpenCodelists

## Usage

``` r
get_coding_systems(codelist_ids)
```

## Arguments

- codelist_ids:

  Character vector of codelist slugs including the version

## Value

Character vector of coding system IDs, `NA` for codelists not found on
OpenCodelists
